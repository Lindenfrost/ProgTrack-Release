# Linux bundled-font license notice

This directory is generated by the native Linux release builder. It contains
the Matplotlib font data copied from matplotlib/mpl-data/fonts/ttf so that a
ProgTrack Linux release can render reports and the user interface without a
host-font installation. ProgTrack and Deutsches Primatenzentrum GmbH do not
claim ownership of these fonts.

The notice covers every file under fonts/matplotlib/ in the generated release.
The exact upstream license files are retained beside the fonts:

- matplotlib/LICENSE_DEJAVU covers the DejaVu family, including the Bitstream
  Vera and Arev attribution and permissions.
- matplotlib/LICENSE_STIX covers the converted STIX TrueType files, including
  the STI Pub Companies, MicroPress, and Elsevier copyrights and the SIL Open
  Font License (OFL) 1.1 terms.

## Computer Modern / BaKoMa TrueType fonts

The bundled cm*.ttf files are the BaKoMa Computer Modern TrueType collection.
Their embedded metadata identifies:

> BaKoMa Fonts Collection, Level-B.

The Matplotlib license documentation records the corresponding BaKoMa
permission notice: the unmodified fonts may be copied and distributed with
the copyright, author, and permission notice intact; modified fonts must retain
the notice and identify the original location. Font embedding in PDF/SVG and
printing are permitted without a separate notice. Matplotlib also documents
the American Mathematical Society's SIL OFL 1.1 terms for its Computer Modern
test-font material. ProgTrack distributes the unchanged Matplotlib/BaKoMa
files and does not relicense or modify them.
