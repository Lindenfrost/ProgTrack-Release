ProgTrack – User Guide

ProgTrack is an interactive application for tracking hormone levels, weights, surgeries and reproductive events in laboratory animals. It visualizes time series, enforces animal-specific limits, and provides planning and reporting tools through optional plugins.

1. Introduction & key concepts

ProgTrack is built around individual animals. For each animal you can record hormone measurements (blood progesterone, urine PdG), weights, sperm parameters, operations and reproductive events. Data are visualized as time-series plots and summarized in statistics.

Important concepts:

  • Animal – one record in the left sidebar. Each animal has a unique name and a specific role.
  • Role – determines how the animal is used (e.g. Egg Donor, Surrogate, Sperm Donor, Offspring, Partner, Breeding Animal) and which limits apply.
  • Measurements – time-stamped data for progesterone, PdG, weights and sperm quality.
  • Events – operations, embryo transfers, pregnancies, births, PGF/FSH injections and other reproductive events.
  • Plugins – optional modules for advanced planning, reporting, embryo tracking and team communication.
Current structure: ProgTrack is modular. The core program owns the animal database, plots, imports, language/style settings, and the main tab shell. Plugins add tabs, dialogs, permission gates, report tools, and workflow-specific data stores. Some modules are full tabs, some are separate windows, and some are feature gates which enable additional controls.

2. Starting ProgTrack & data files

2.1 Starting the program

  • Open Launcher.exe in the portable ProgTrack folder.
  • The launcher starts the first ProgTrack.v.*.py file it finds beside itself, in natural filename order. An explicit script can be passed with --script.
  • Keep Plugins, icons, lang, manual, and the active payload script beside Launcher.exe.
  • The compiled launcher already contains the required Python runtime; users of the portable bundle do not need to install Python packages.
Tip: If the application does not start, check launcher_error.log and launcher_fault.log in the launcher folder.

2.2 Data and settings files

ProgTrack stores data in JSON files in the program or working directory:

FilePurpose
progtrack_daten.jsonMain animal and measurement database.
progtrack_settings.jsonUser interface and plotting settings (language, colors, styles, etc.).
Do not edit these JSON files by hand unless you know exactly what you are doing. Use the ProgTrack UI instead.
Tip: For safe manual backups, close ProgTrack and then copy progtrack_daten.json, progtrack_settings.json or the whole ProgTrack folder to a protected location.

2.3 Sample Excel files

The ProgTrack folder may contain example Excel files (Real_Blut.xlsx, Real_Urine.xlsx, Real_Sperma.xlsx, Real_Gewichtel.xlsx). These show the expected structure for importing measurements.

3. User interface overview

The main window is organized as follows:

  • Menu bar – File, Tools, Settings (Language & Style), Info (About the Program).
  • Left sidebar – lists available and archived animals, provides filters by cycle phase and quick actions (new, edit, import, archive, restore, delete).
  • Main area – usually two top-level tabs: Plots (time-series graphics) and, if the Animal Reports plugin is installed, Reports (per-animal PDF-style summaries).
  • Status bar – messages about imports, errors and processing steps. When the Master Track plugin is installed, the status bar also shows the current user and login state (or “Guest” in read-only mode). Click the status label to access a quick menu for login, logout or password change.

5.4 PdG → Progesterone Converter

ProgTrack can estimate blood progesterone values from urine PdG measurements using a configurable conversion formula. The resulting estimates are used for the Unified Prog. curve and can influence phase shading and decisions in the plots.

Open the converter via Tools → PdG→Progesterone Converter. First select an animal that has both blood progesterone and PdG measurements. The dialog shows paired points where blood and PdG values are available for the same day.

Workflow:

  • Use Auto Fit to calculate a best-fit conversion formula from PdG to blood progesterone for the currently selected animal.
  • Optionally adjust the coefficients manually in the input fields (for example, to try linear vs. log-like relationships or to match a known reference).
  • Click Save / Apply to store the formula for that animal (or according to your local configuration, e.g. per role or globally). The stored formula is then used for future recalculation of Unified Prog. in plots and reports.
Recommendation: Fit the conversion formula on animals with good parallel sampling (several days with both blood and PdG values). Changing the formula will change the appearance of Unified Prog. and can affect phase classification; document major changes for your team.

6. Plots & data exploration

6.1 Plot modes

On the Plots tab:

  • Choose one or more animals in the sidebar (up to a configured maximum).
  • Select a mode:
    • Combined – unified view of progesterone and PdG.
    • Blood (Pgr) – blood progesterone only.
    • Urine (PdG) – urine PdG only.
  • Toggle separate checkboxes for Progesterone, Weight and Events to show/hide those curves or markers.

For readability and performance there is a maximum number of animals that can be shown in one plot at the same time (by default up to 5 animals). If you select more animals than allowed, extra selections are automatically deselected and only up to the maximum are plotted.

6.2 Line styles, markers and colors

Use the Display / Line Style groups to adjust how progesterone, weight and sperm series are drawn.

For a more global configuration, use Settings → Style (see section 7).

6.3 Exporting plotted data

Use File → Export Reports (.xlsx) to export data for selected animals and a given date range to Excel. You can then perform further analysis or share the file.

Tip: Use Excel export to prepare figures and summaries for reports: select exactly the animals and time window you need in ProgTrack, then format and annotate the exported sheet in Excel or your statistics software.

7. Language & appearance

7.1 Language selection

Open Settings → Language to switch the user interface language. The available languages are listed by their own names (autonyms), independent of the current UI language:

  • English
  • Deutsch
  • Русский
  • Italiano

Changing the language rebuilds menus, dialogs and labels using the corresponding messages_*.json file.

7.2 Style settings

Use Settings → Style to open the style settings dialog. Here you can configure:

  • Main colors for progesterone, weight, PdG and sperm curves.
  • Colors for FSH injections and event markers (PGF, embryo transfers, operations, pregnancies, abortions, births, special measurements).
  • Markers for each measurement type (e.g. circle, triangle).
  • Line styles.

Use Reset to defaults if you want to restore the standard color scheme.

8. Saving & exporting

8.1 Saving the database

Use File → Save Database to explicitly write the current state to progtrack_daten.json. Automatic saving may also occur during certain operations, but an explicit save is recommended after larger editing sessions.

Tip: Get into the habit of saving just before bulk imports or complex plugin operations (for example the OP Planner). If anything unexpected happens, you can roll back to the last known-good JSON backup.

8.2 Excel export

File → Export Reports (.xlsx) opens a dialog where you:

  • Select animals and a date range.
  • Confirm to export all relevant measurements and events into an Excel workbook.

8.3 PDF export (with Animal Reports plugin)

If the Animal Reports plugin is installed, the menu item File → Export Reports (.pdf) becomes available. It uses the Reports plugin to generate one PDF per animal and month. You can choose:

  • Output directory.
  • Animal(s) to export.
  • Year and month.
  • Report language.

10. Troubleshooting & tips

10.1 Plugins not available

If a plugin menu entry is disabled or displays a message such as "plugin is not installed", check that the corresponding subfolder exists under Plugins and contains the expected files.

10.2 Excel import errors

  • Missing columns – use the current column names expected by the code: blood progesterone files need Name, Datum, Progesteron (ng/ml), and F; PdG files need Name, Datum, and PdG (µg/mg Cr); weight files need Name, Datum, and Gewicht; sperm files need Datum, Name, % Motility, % Progressive, and Sperms/ml.
  • Missing runtime libraries – the portable launcher should already include the import libraries. If an import library is missing in a portable release, rebuild or replace the launcher bundle; only source-mode users need to install packages such as openpyxl or pandas.
  • Invalid rows – rows with invalid dates, empty names, or non-numeric values are skipped; clean the Excel file and import again.

10.3 Performance and data safety

  • Avoid editing very large Excel files at once; consider importing data in batches.
  • Use File → Save Database regularly.
  • Back up progtrack_daten.json periodically via your normal file backup procedures.

10.4 Technical logs

Lord and Master accounts can use Master Track → Open tech logs to open the folder that contains technical support logs. This is separate from the regular Logs action, which is used for audit and animal-change logs.

The technical log folder contains files such as progtrack.log, launcher logs when available, and log_locations.txt. The log_locations.txt file lists relevant application, launcher, audit-log, and application-folder paths for support and troubleshooting.
